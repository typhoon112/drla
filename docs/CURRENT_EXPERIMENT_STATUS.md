# Current Experiment Status

Last updated: 2026-05-26

Logging policy note: SwanLab charts are only meaningful for scripts with an optimizer/backward training loop. Historical run ids attached to pure scorer eval, trace, frontier, adaptive-halt eval, risk-gated eval, or aggregation are record pollution from before the policy hardening; use their local `summary.json` artifacts only and do not read them as training curves.

## Decision

The main experimental path is now:

```text
official Cola VAE + official Cola DiT
+ block-wise rollout trace
+ decoder probe
+ oracle readiness frontier
+ multi-signal readiness / halt model
```

Do not treat DiT LoRA accuracy gains, the custom small Cola-latent prior, or GSM8K-only diagnostics as the main route. The main question is whether accumulated Cola latent blocks contain useful answer-readiness signals.

- `drla/scripts/analyze_cola_risk_gated_halt_decisions.py`: reconstructs sample-level risk-gated halt decisions from a summary/checkpoint pair and diagnoses losses/gains against fixed-final and prediction-stability.

For `utility_mse`, `utility_pairwise`, and `decomposed_expected_utility`, policy thresholds are applied to raw scores rather than sigmoid probabilities; `utility_soft_bce` uses probability thresholds and exposes `--utility-temperature`.
